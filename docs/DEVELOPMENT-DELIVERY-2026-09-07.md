# 内容链路交付 · 2026-09-07

## 本轮版本

实现内容计划 → 内容创作 → 内容库 → WordPress 发布管理的首个闭环版本。现有 UI 改动已保留。

- 内容简报可独立创建；计划与生成任务关联；支持定时生成、失败后重新生成、防重复扣费；执行状态由后台结果更新。
- 生成原稿与人工编辑采用统一版本；保存时校验基础版本，避免多人覆盖；历史版本可载入另存。
- 每个版本保存正文哈希、五项机器检查及独立人工审核；事实确认不是机器事实核验，100 分仅表示基础检查通过。
- 发布请求绑定获批版本；即使随后编辑了新版，已批准的发布仍使用原获批正文；人工确认后才进入发布队列。
- WordPress 使用稳定 Slug、持久回执和内容回读验证；网络结果不确定时先核验，避免盲目重复创建；明确拒绝允许修正后重试。
- 内容库显示最新版本、审核和发布状态；支持筛选、CSV 导出、归档与恢复；修复窄窗口操作按钮不可达。
- 内容接口和审核同时校验组织、项目范围与角色；修复失效会话登录参数和语言组件恢复旧动态文字的问题。

## 当前使用边界

自动发布平台为 WordPress；其他平台入口尚未提供自动发布。AI 模型未配置时仅生成结构化草稿，页面会明确提示。已发布文章撤回或更新暂通过 WordPress 后台处理；不确定写入会保留核验状态，必要时需人工核对 CMS。

线上预检：当前没有启用的内容模型，也没有 CMS 连接，因此不能声称完成真实付费模型或真实 WordPress 的外部验收。管理员需在模型设置配置提供商，在项目数据连接配置 WordPress 应用密码并授权发布后，由测试文章完成最终接入验收。

已有旧内容会在首次访问内容工作台时迁移为可审核版本；旧审核项必须重新提交具体版本。旧发布请求缺少版本绑定时不会自动执行旧正文。
