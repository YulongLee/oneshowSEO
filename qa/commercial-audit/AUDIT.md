## 本轮修复

- 清理了 11 个 lint 错误和 8 个警告，包括不稳定渲染时间、副作用中同步更新状态、未使用依赖与弱类型。
- 修复了工作台中间态 HMR 报错，并通过全量构建验证。
- 保留试用套餐、审批、用量限制和管理权限的真实边界。

## 审计步骤

1. 营销首页：价值主张、自动化工作流和试用 CTA 清晰。
2. 注册与登录：邮箱验证码、找回密码、条款确认和 returnTo 跳转完整。
3. 工作台总览：真实证据 SEO 分数、待接入数据状态、Agent 编排和任务入口一致。
4. 项目中心：项目健康度、最近运行、标签和团队归属可追踪。
5. Agent Center：运行状态、工作步骤、执行日志和成本入口可见。
6. Approval Center：高风险改动需人工审批，包含证据、变更预览和操作轨迹。
7. Billing：试用套餐、用量上限、账单状态和升级入口保持诚实。
8. API & MCP：已开放与规划中能力分开展示，API Key 仅哈希存储。
9. 管理后台：普通用户被安全重定向，admin API 返回 403；管理账号可管理用户与服务端数据源。
10. 生产运行：公开页可访问，受保护 API 拒绝匿名请求。

## 上线后商业增强项（不阻塞发布）

- 配置 GSC、GA4、排名/外链供应商和 CMS 真实凭据。
- 接入 Stripe/支付宝/微信支付后再开放付费按钮。
- 对前端大 chunk（>500KB）进行按模块懒加载。
- 增加自动化键盘、读屏、色彩对比与移动端实机回归。

## 无障碍风险

- 当前视觉与 DOM 验收无法证明完整键盘操作、焦点可见性和读屏顺序。
- 多处小号灰色文字可能在低亮度屏幕上对比不足。
- 工作台侧栏在移动端转为双列按钮，长导航的触控与滚动仍需实机验证。
- 图表缺少文本替代和数据表形式。
